# 商业级管理员后台控制台

## 背景

上一版 `/admin` 只覆盖支付、账本和 Webhook 的骨架，不能支撑真实商业运营。BloomX 作为全球 API 能力交易市场，生产后台必须覆盖用户、商家、商品、订单、支付、积分账本、退款、工作流、Webhook、结算、审计和系统配置。

## 变更目标

- 将 `/admin` 从支付单页升级为完整商业后台控制台。
- 读取真实 Firestore 运营集合，失败时暴露权限/索引/配置问题，不使用假数据掩盖。
- 提供运营总览、待办队列、生产风险、模块数据覆盖和配置闸门。
- 保留未登录预览，但真实敏感动作必须由管理员角色和服务端审计 API 执行。

## 不做范围

- 本次不在前端直接执行退款、结算、权限变更或 Webhook 重放。
- 本次不在前端保存支付密钥或工作流密钥。
- 服务端动作 API、审计写入和 Firestore rules 将作为下一步继续实现。
