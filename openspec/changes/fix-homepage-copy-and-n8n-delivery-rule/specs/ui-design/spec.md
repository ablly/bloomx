## ADDED Requirements

### Requirement: 首页中文文案不得乱码
首页和全局导航中的中文文案 MUST 使用有效中文，并准确表达 BloomX 的 API 能力交易市场定位。

#### Scenario: 中文首页 hero
- **WHEN** 用户在中文语言环境打开首页
- **THEN** hero 主标题显示有效中文
- **AND** 用户菜单中的角色、账户中心等文案显示有效中文

#### Scenario: 背景交易故事线
- **WHEN** 首页背景故事阶段在中文语言环境显示
- **THEN** 每个阶段标题和描述均为有效中文
- **AND** 文案表达商家供给、平台路由、买家调用和收益结算的闭环
